## 附录：新项目启动 checklist

1. `./scripts/init.sh` 替换占位符；分配 Metro 端口与模拟器 UDID 并登记（CLAUDE.md §一）。
2. 写领域铁律 → eslint 规则位落地。
3. app.json：privacyManifests 按实际 API 调整、权限中文文案。
4. schema v1 → `pnpm verify` 全绿 + Maestro smoke 绿。
5. 需要后端 → `server/` 骨架（先跑 `server/scripts/accept.sh` 验收）。
6. 需要原生能力 → `create-expo-module --local`，先打通 App Group JSON DTO 通路。
7. git 第一天提交；CLAUDE.md 标注「基于 template v0.1.0」。
